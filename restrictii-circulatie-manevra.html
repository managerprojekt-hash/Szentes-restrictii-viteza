Anexa 19 (PDF)

      Traseul unei închideri urmează rețeaua TUI între cele două stații din anexă, iar lungimea este suma secțiilor parcurse; unde traseul nu poate fi urmărit, linia este trasă drept între stații (marcată „aproximativ”). Stațiile sunt poziționate după rețeaua TUI și după OpenStreetMap. Felul închiderii este dedus din coloana „închidere totală” și din observații (fir, ferestre orare, restricții de viteză). Anexa este verificată automat la începutul fiecărei decade; fiecare versiune nouă este păstrată.
